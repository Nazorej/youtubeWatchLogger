# youtubeWatchLogger

Личный журнал просмотренных YouTube-роликов. Скрипт забирает метаданные видео
через yt-dlp, дописывает их в Excel-файл и пересчитывает статистику времени
просмотра по дням, месяцам и годам.

## Возможности

- Добавление видео по ссылке: название, автор, ID, дата просмотра, длительность
- Защита от дублей — одно видео не добавится дважды
- Автоматическая статистика: суммарное время просмотра за день / месяц / год
- Даты и длительности хранятся как значения Excel, а не текст:
  сортировка, фильтры и формулы по журналу работают корректно
- Корректный показ сумм больше 24 часов: используется формат длительности
  [h]:mm:ss, а не времени суток
- Готовое оформление: стилизованные шапки, зебра, границы, закреплённый заголовок
- Обратная совместимость: старые записи в текстовом формате
  (даты dd.mm.yy, время HH:MM:SS) распознаются и учитываются в статистике

## Структура книги youtube.xlsx

| Лист | Колонки | Форматы | Назначение |
|---|---|---|---|
| Просмотры | Дата, Время, Автор, ID, Название | DD.MM.YYYY, [h]:mm:ss | журнал: одна строка — одно видео |
| Статистика по дням | Дата, Просмотрено | DD.MM.YYYY, [h]:mm:ss | сумма длительностей за каждый день |
| Статистика по месяцам | Месяц, Просмотрено | MM.YYYY, [h]:mm:ss | сумма за каждый месяц |
| Статистика по годам | Год, Просмотрено | 0, [h]:mm:ss | сумма за каждый год |

## Требования

- Python 3.8+
- yt-dlp — https://github.com/yt-dlp/yt-dlp
- openpyxl

## Установка

    git clone https://github.com/Nazorej/youtubeWatchLogger.git
    cd youtubeWatchLogger
    pip install yt-dlp openpyxl

Проверка, что yt-dlp доступен:

    yt-dlp --version

## Использование

Впишите ссылку на видео в конце main.py:

    if __name__ == "__main__":
        processUrl("https://youtu.be/ВАШ_ID")

и запустите:

    python main.py

Пример вывода:

    ✔ Добавлено: <название видео>

Файл youtube.xlsx создаётся автоматически в той папке,
из которой запущен скрипт, — запускайте его из папки проекта,
чтобы журнал всегда лежал в одном месте.

## Обновление со старой версии

Если youtube.xlsx создан ранней версией проекта без листов статистики,
один раз запустите миграцию из папки, где лежит файл:

    python migrate.py

Скрипт добавит недостающие листы «Статистика по дням / месяцам / годам»,
пересчитает статистику по всей истории журнала и применит оформление.
Если все листы уже на месте, файл останется нетронутым.

## Файлы проекта

| Файл | Назначение |
|---|---|
| main.py | точка входа: журнал, защита от дублей, пересчёт статистики |
| ytService.py | получение метаданных видео через yt-dlp |
| excelFormatter.py | оформление листов: стили, ширины колонок, форматы дат и времени |
| migrate.py | разовая миграция старого youtube.xlsx: добавляет листы статистики |

## Нюансы

- **Закройте youtube.xlsx в Excel** перед запуском main.py или migrate.py —
  иначе сохранение упадёт с PermissionError.
- Время просмотра хранится как доля суток, поэтому формат [h]:mm:ss
  обязателен: обычный формат времени показал бы, например, 25 часов
  за месяц как «01:00:00». Формат проставляется автоматически.
- Записи, оставшиеся со старых версий в текстовом формате, не мешают:
  при пересчёте статистики они распознаются и корректно складываются.
- Статистика пересчитывается с нуля при каждом добавлении видео —
  для личного журнала это мгновенно и исключает любые расхождения.
- Возрастные и приватные видео могут требовать авторизации —
  при необходимости добавьте флаг --cookies-from-browser
  в команду yt-dlp (см. ytService.py).
- Ссылки на плейлисты обрабатываются: берётся первое видео.
- Прямые трансляции (без длительности) не добавляются.
- Периодически обновляйте yt-dlp (yt-dlp -U) — YouTube периодически
  меняет внутренние API.
